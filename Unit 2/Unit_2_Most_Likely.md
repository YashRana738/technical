## 1. Technical Report — Structure + Features (Most likely 10-mark)

**What is it?** A formal document that presents the process, findings, and conclusions of technical work.

**Quick structure to memorize:**
> Title → Abstract → TOC → Introduction → Methodology → Results → Discussion → Conclusion → References → Appendix

**Key features (memorize 5):**
1. Clear and concise language
2. Structured format with headings
3. Uses graphic aids (tables, charts)
4. Objective — no personal opinions
5. Properly referenced

**Types:** Feasibility, Progress, Lab, Research, Annual report.

---

## 2. Abstract Types (Most likely 5-mark)

| | Descriptive | Informative |
|---|---|---|
| **What it says** | "This paper is about X" | "This paper found X using Y method" |
| **Results?** | No | Yes |
| **Length** | 50–100 words | 150–300 words |
| **Standalone?** | No | Yes |

**Memory trick:** *Descriptive = Describes the topic. Informative = Informs the reader of everything.*

---

## 3. Graphic Aids (Most likely 5-mark)

**Types:** Tables, bar charts, pie charts, line graphs, flowcharts, diagrams.

**Advantages (memorize 4):**
1. Simplify complex data
2. Allow quick comparison
3. Highlight trends/patterns
4. Improve readability

---

## 4. Referencing — APA vs IEEE (Most likely 5-mark)

| | APA | IEEE |
|---|---|---|
| **Field** | Social sciences | Engineering/CS |
| **In-text** | (Author, Year) | [1], [2] |
| **Reference order** | Alphabetical | Order of appearance |

**Just remember:** APA = author name + year. IEEE = numbers.

---

## 5. Plagiarism + Paraphrasing (Most likely 5-mark)

- **Plagiarism** = copying without credit. Academic offense.
- **Paraphrasing** = rewriting in your own words + citing the source.
- **Patchwriting** = changing only a few words (bad paraphrasing — still plagiarism).

**Quick example:**
- Original: "AI has changed how students learn."
- Patchwriting ❌: "AI has transformed how students study."
- Good paraphrase ✅: "The learning process of students has been reshaped by artificial intelligence."

## 6. Editing vs Proofreading (Can appear as 5-mark)

| | Editing | Proofreading |
|---|---|---|
| **Focus** | Content + structure | Spelling + grammar |
| **When** | During revision | Final step |
| **Depth** | Deep (may rewrite) | Surface (fix errors) |
