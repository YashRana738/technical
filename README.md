# Technical Writing & Communication Skills Study Portal

A clean, responsive, and unit-wise study portal for Technical Writing and Communication Skills. This repository contains structured question-bank answers, quick revision notes, and raw study materials, all accessible through a web-based interface.

## 🚀 Live Site
Check out the study portal here: [https://YashRana738.github.io/technical/](h[ttps://YashRana738.github.io/technical/](https://yashrana738.github.io/technical_writing/))

## 📂 Repository Structure

- **Units 1-5**: Each unit contains:
  - `10_and_5_Mark_Answers.md`: Detailed explanations for long and short-form questions.
  - `Most_Likely.md`: Condensed "Quick Revision" notes focusing on high-priority topics.
- **Raw Notes**: `Technical_Writing_and_Communication_Skills_Notes.md` - Comprehensive raw study material covering the entire syllabus.
- **Web App**:
  - `index.html`: Main portal structure.
  - `styles.css`: Clean, mobile-friendly design (Light/Dark modes).
  - `script.js`: Dynamic content loader and markdown parser.

## ✨ Features

- **Unit-Wise Navigation**: Easy switching between Unit 1 to 5.
- **Dual Mode Notes**: Toggle between comprehensive answers and quick revision notes.
- **Raw Notes Tab**: Quick access to the full, unformatted syllabus notes.
- **Dark/Light Mode**: User-friendly theme switching.
- **Mobile Responsive**: Optimized for studying on both mobile and desktop devices.
- **Automated Deployment**: Powered by GitHub Actions and GitHub Pages.

## 🛠️ Built With

- HTML5 & CSS3
- JavaScript (Vanilla)
- [Marked.js](https://marked.js.org/) for Markdown parsing
- GitHub Actions for CI/CD

## 📖 How to Use

1. **Select Unit**: Use the top navigation bar to select the Unit you want to study.
2. **Select Type**: Toggle between "Full Answers" for deep study or "Quick Revision" for last-minute prep.
3. **Raw Notes**: Click the "Raw Notes" tab at the top to see the complete set of communication skills notes.
4. **Theme**: Use the sun/moon icon at the top right to switch between Light and Dark mode.
